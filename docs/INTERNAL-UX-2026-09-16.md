# Internal UX before production — отчёт

Дата: 16 сентября 2026

## До → после

| Экран | До | После |
| --- | --- | --- |
| Результат | Длинный HR-текст и весь список проблем до основного действия | Сначала статус результата, вывод, главные замечания и CTA; полный разбор и остаток замечаний доступны ниже |
| Вакансия | Пакетные остатки и пустые секции конкурировали с решением | Отдельные выводы для vacancy-only и match; показываются только наполненные блоки, релевантный остаток указан рядом с действием |
| Улучшение | Готовность смешивалась с вопросами, скачивание было в нижнем ряду | Состояние «Резюме готово», DOCX сразу под итогом, сравнение и редактор ниже |
| Адаптация | Общие пакетные метрики и повторная проверка были важнее файла | Состояние «Резюме под вакансию готово», DOCX — главное действие, recheck — вторичное |
| Кабинет | Общие остатки пакета и новый разбор конкурировали с текущей задачей | Сначала готовый документ или продолжение незавершённой работы, затем история и пакет |

## Новый маршрут

`результат → исправить или проверить вакансию → ответить только подтверждёнными фактами → скачать готовый DOCX → вернуться к версии из кабинета`

Самостоятельная ветка вакансии: `вставить вакансию → увидеть требования → добавить резюме → получить персональное сопоставление → адаптировать → скачать DOCX`.

## Состояния AI

- Mock/test показывает заметное предупреждение и прямо говорит, что это демонстрация интерфейса, а не профессиональная оценка.
- Ошибка live AI не создаёт готового результата и предлагает повторить запрос, сохраняя введённые данные.
- Полноценный результат не меняет существующие версии правил, evidence/grounding и контекст вакансии.

## Проверено

- `npm run lint`
- `npm run typecheck`
- `npm run build`
- полный изменённый browser-flow в mock-режиме
- vacancy-only и adaptation browser-flow
- 15 локальных vacancy regression-тестов
- 2 regression-теста пользовательских ошибок
- desktop/mobile screenshots и отсутствие горизонтального переполнения

## Ограничения

- Live AI и полный `suite=full` не запускались по установленному режиму проверок.
- Production deploy, YooKassa, backup/restore и production smoke остаются в `PRE-RELEASE-CHECKLIST.md`.
- Визуальная готовность этапа остаётся за Product Owner; разработка не объявляет продукт принятым самостоятельно.
