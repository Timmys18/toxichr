## Часть 1: Оценка и переосмысление продукта

### Стартовая критика (Tim)
- UI убогий: шрифты как прописью (MS Word), жёлтый цвет (не технологичный), плохая типографика
- Копирайт неправильный: фрейм судьбы, извинительные ноты вместо уверенности
- Язык общения с пользователем хуже, чем говорит о себе продукт

### Суть переосмысления
**Старый фрейм (судебный):**
- "Твоё резюме выглядит хуже твоего опыта" → наезд без приглашения
- Театр как "следствие" → протоколы, "доказательства", "улики"
- Вердикт как "приговор суда"
- Извинительные ноты "не про тебя как человека" → шоу, которое извиняется за себя

**Новый фрейм (стендап):**
- "Самый токсичный HR тебя заждался" → приглашение на шоу
- Разбор как живой стрим: персонажи (не следователи) читают резюме вживую
- Персонажи — HR-ы со сцены, панчи по тексту (не по человеку)
- Сарказм — приглашение на шоу, а не вердикт до загрузки
- Этика зашита в промпты и правила, не на карточке вердикта

### Ключевые языковые сдвиги
| Было | Стало |
|------|-------|
| "Показать улики" | "Полный разбор" |
| "Доказательства" | "Конкретика" или "Факты vs слова" |
| "Ясность роли" | "Кто ты вообще" |
| "Соответствие уровню" | "Заявка vs реальность" |
| "Убедительность" (балл) | "Оценка от персонажа" (58/100 от Вадика) |
| "карьерные показания" | резюме читается вживую |
| "следствие" → "театр" | живой стрим с репликами |

## Часть 2: Движок v3

### Архитектура
Из трёх LLM-этапов:
1. **Extract (Evidence Map)** — карта заявлений резюме с дословными цитатами, каждая валидируется против текста. Признаки: тип (achievement/duty/skill), наличие метрики, масштаба, личного действия, результата, дженерик-ность.
2. **Score** — LLM оценивает 8 измерений (позиционирование, конкретика, личный вклад, масштаб, соответствие уровню, карьерная логика, структура, язык) с обоснованиями. Итоговый балл считается по весам ТЗ §7.1.
3. **Persona** — персонаж получает карту доказательств и обоснования, пишет разбор под твой текст, не шаблон.

### Технология
- `/api/analyses/stream` — SSE-стрим с реальными событиями анализа
- Theater events из evidence map — находки не из регэкспов, из LLM
- Gateway поддерживает температуру и токены по этапам (аналитика 0.1-0.15, персона 0.9)
- Fallback на sync-маршрут если SSE недоступен

### Что изменилось в коде
- `src/lib/ai/evidence.ts` — extract и score этапы (новое)
- `src/lib/ai/pipeline.ts` — переписан под v3, события наружу
- `src/lib/ai/gateway.ts` — температура/токены per-stage
- `src/lib/run-analysis.ts` — общий оркестратор (новое)
- `/api/analyses/stream` — SSE-роут (новое)
- `/api/analyses` — рефакторен на run-analysis.ts
- `src/app/analyzing/analyzing-client.tsx` — живой театр из SSE, fallback на sync

## Часть 3: Дизайн и UI

### Основная критика (v1 эталон)
- Шрифты: Inter Tight с курсивом → выглядит как школьная курсовая
- Цвета: лайм #c9f231 читается как жёлтый, не технологичный, не "токсичный"
- Компоненты: glass-морфизм + стеклянные панели + чат-пузыри = SaaS для школьников
- Палитра: тепловая (лайм, золото, оранжевый) вместо холодной технологичной

### Требования (v2 эталон)
- Шрифты: Onest (variable, 100-900) + JetBrains Mono, вшиты в HTML (base64), никаких сетевых зависимостей
- Цвета: **холодная моно-палитра** — графит #0a0f0d с холодной зелёно-синей атмосферой
  - Акцент: токсичный неоновый зелёный #2ce08b (радиоактивная зелень, не лимон)
  - Данные: электрик-синий #5b8cff
  - Критика: красный #ff4d3d
  - Всё, палитра закрыта
- Компоненты: **инструмент, не лендинг**
  - Резюме-образец в центре как главный объект с HUD-разметкой
  - Hairline-линии (выноски), крупные цифры (30-104px)
  - Pill-кнопки, плоская белая CTA (не градиент)
  - Моно-навигация (без mono-капса)
  - Strip данных вместо стеклянных карточек
- Типографика:
  - Заголовок: вплоть до 104px, -0.045em трекинг
  - Данные: font-variant-numeric tabular-nums
  - Метки: JetBrains Mono 11px с трекингом .22em
  - Ни один курсив, ни одна прописная (вольная типография)

### Вдохновение (из рефов, но не копирование)
- **Orion** (job matching): массивная типографика, уверенность, центральный объект (3D модель)
- **Hydraoo** (maritime): сдержанность, дорогость, ничего лишнего, фото-фон как атмосфера
- **BootStats** (analytics): тонкие линии, плотность данных, тёмная палитра
- **Weather app** (iOS): атмосфера + glass + живая разметка

## Часть 4: Эталон v2 — "Инструмент"

### Что показано
Резюме-образец под сканером с реальными фрагментами:
- "Ответственный, коммуникабельный..." → метка "вода" (оранжевый фон, иконка)
- "Принимал участие в реализации стратегических проектов" → метка "не доказано" (красный)
- "Сократил цикл поставки с 18 до 7 дней" → метка "зачёт" (зелёный)

Бегущая линия сканирования (animation: scan 3.4s infinite) показывает, что система читает текст.

HUD-выноски hairline-линиями:
- **Обязанностей:** 18 (красным)
- **Результатов:** 3
- **Корп. вода:** 82%  (красным)
- **Оценка Вадика:** 58/100 (зелёным, показывает, что персонаж выстроил мнение)

### Внизу: Data Strip
```
4 HR-персонажа       | 100% панчей привязаны к цитатам | 2:47 средняя длительность | 0 шаблонных шуток
(один токсичнее)     | (честность механики)            | (быстро)                   | (разбор под твой текст)
```

### Философия
- Продукт показан, не рассказан
- Центр внимания — анализируемый резюме-образец
- Hairline-выноски вместо glass-панелей
- Плоская белая pill-кнопка вместо градиента
- Цифры 30-104px — главный визуальный герой
- Моно-графит + токсичный зелёный + данные (синий, красный)
- Никакого школьного дизайна
