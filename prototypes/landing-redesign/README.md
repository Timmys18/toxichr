# Прототип главной ToxicHR

Отдельная локальная страница для обсуждения дизайна. Рабочий сайт и маршруты Next.js не меняются. Файлы и текст резюме здесь никуда не отправляются, оплата не работает.

Стиль, шрифты, цвета, портреты и первый экран взяты из действующего ToxicHR. Вверху сохранён выбор всех четырёх HR с исходными текстами. Ниже — четыре карточки рядом, схема работы, цены и финальный призыв. Из референса взят только порядок блоков; вымышленные показатели и отзывы не перенесены. Блок примера удалён. Загрузка файла и вставка текста оформлены как отдельные кнопки; галки согласия на главной нет.

Ссылки «Войти» и «Личный кабинет» открывают действующие страницы ToxicHR. Если пользователь ещё не вошёл, кабинет направляет его на вход. Согласие на обработку резюме уже запрашивается при регистрации на действующем сайте; этот локальный прототип не содержит собственной авторизации и не отправляет данные.

Открыть локально: запустить из этой папки `python -m http.server 5174`, затем перейти на `http://127.0.0.1:5174/`.

Для сравнения первого экрана созданы две самостоятельные визуализации одной и той же главной: `compare.html?view=equal` — четыре равные карточки HR сразу под заголовком; `compare.html?view=carousel` — крупная ручная карусель с видимыми соседними карточками. В обеих версиях остальная страница одинаковая, отдельного повторного блока HR нет. Переключение HR работает локально; загрузка и вход на самом макете не выполняются.
