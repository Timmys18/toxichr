# Прототип главной ToxicHR

Отдельная локальная страница для обсуждения дизайна. Рабочий сайт и маршруты Next.js не меняются. Файлы и текст резюме здесь никуда не отправляются, оплата не работает.

Стиль, шрифты, цвета, портреты и первый экран взяты из действующего ToxicHR. Вверху сохранён выбор всех четырёх HR с исходными текстами. Ниже — четыре карточки рядом, схема работы, цены и финальный призыв. Из референса взят только порядок блоков; вымышленные показатели и отзывы не перенесены. Блок примера и галка согласия в этом макете убраны по решению Product Owner.

Открыть локально: запустить из этой папки `python -m http.server 5174`, затем перейти на `http://127.0.0.1:5174/`.
