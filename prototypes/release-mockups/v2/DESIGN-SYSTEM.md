# Визуальные правила макетов

Обе страницы используют `system.css`. Новые макеты подключают его до своего файла раскладки.

- Один шрифт: Onest. Заголовок страницы — `h1`, заголовок блока или карточки — `h2`/`h3`, остальное — основной текст.
- Только один мелкий размер (`--type-note`) для дат и второстепенных данных. Важный текст не мельче 16 px.
- Цвета берутся из общих переменных: фон, поверхность, текст, приглушённый текст, граница, зелёный акцент. Статусы передаются словами, без произвольной цветовой шкалы.
- Кнопки собираются из `.button` и её общего варианта. Радиус, граница и отступы не задаются заново на каждой странице.
- На экране остаются только данные и действия пользователя. Не выводить технические пометки, декоративные счётчики, повторы заголовков и пояснения о том, что это макет.
